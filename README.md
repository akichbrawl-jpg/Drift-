# Дрифт-Сити — сборка APK

1. Создай бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузи в него ВСЕ файлы из этой папки (включая скрытую папку .github).
3. Открой вкладку Actions -> Build APK -> дождись зелёной галочки (5-10 минут).
4. Открой завершённый запуск, внизу в Artifacts скачай drift-city-apk (внутри app-debug.apk).
5. Перекинь APK на телефон и установи (разреши установку из неизвестных источников).

Игра при первом запуске загружает библиотеку 3D из интернета, нужен интернет.
Прогресс сохраняется на телефоне (localStorage + cookie).
Для публикации в Google Play нужна подписанная release-сборка (AAB).
